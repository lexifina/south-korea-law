제16조 (용도지구)
①내무부장관ㆍ도지사 또는 군수는 공원의 효율적인 보호와 이용을 도모하게 하기 위하여 다음 각호의 용도지구를 공원계획으로 결정한다.
1. 자연보존지구:자연보존상태가 원시성을 가지고 있거나 보존할 동ㆍ식물 또는 천연기념물등이 있거나 자연풍경이 특히 수려하여 특별히 보호할 필요가 있는 곳
2. 자연환경지구:자연보존지구ㆍ취락지구ㆍ집단시설지구를 제외한 전지구
3. 취락지구:주민의 취락생활 및 농경지 또는 농어촌의 생활근거지로 유지ㆍ관리할 필요가 있는 지구
②제1항의 규정에 의한 용도지구안에서의 허용행위의 기준은 다음 표와 같다.
+------------------+---------------------------------------------------------+
| 구 분 | 허 용 행 위 |
+------------------+---------------------------------------------------------+
| 1．자연보존지구 |가．학술연구 또는 자연보호상 필요하다고 인정되는 행위 |
| |나．최소한의 공단시설의 설치 및 사업 |
| |다．군사시설ㆍ통신시설ㆍ항로표식시설ㆍ수원보호시설등으로 |
| | 서 이 지역이 아니고는 설치할 수 없다고 인정되는 최소 |
| | 한의 시설의 설치 |
| |라．관할도지사를 거쳐 문화체육부장관의 추천이 있는 사찰의|
| | 복원과 사찰경내지에서의 불사를 위한 시설 및 그 부대시|
| | 설의 설치 |
| |마. 문화체육부장관이 종교법인으로 허가한 종교단체의 시설 |
| | 물중 공원지정이전에 건립한 기존 건축물에 대한 내무부 |
| | 령이 정하는 증축ㆍ개축ㆍ재축ㆍ복원 및 그 부대시설의 |
| | 설치 |
| |바．자연보존상태의 원시성이나 수려한 자연풍경을 현저히 해|
| | 하지 아니하는 범위안에서 산림법에 의한 조림ㆍ육림 및 |
| | 림도의 설치 |
+------------------+---------------------------------------------------------+
| 2．자연환경지구 | 가．자연보존지구에서의 허용행위 |
| | 나．내무부령이 정하는 현황지목변경을 허용기준범위내에서 |
| | 의 1차산업행위 또는 초지조성행위 및 그 부대시설의 설 |
| | 치행위 |
| | 다．밀집하지 아니하는 공원시설의 설치 및 사업 |
| | 라．조림ㆍ육림ㆍ벌채 기타 국방상ㆍ공익상 필요한 최소한의|
| | 행위 또는 시설의 설치 및 내무부령이 정하는 국민경제상|
| | 필요한 시설의 설치 |
| | 마．공원지정 이전의 기존 건축물로서 자연풍경과 조화되도 |
| | 록하는 내무부령이 정하는 규모이하의 증축ㆍ개축ㆍ재축 |
| | 및 그 부대시설의 설치와 천재ㆍ지변이나 공원사업으로 |
| | 이전이 불가피한 건축물의 이축 |
| | 바. 공원자원을 보호하고 공원입장자의 안전을 도모하기 위 |
| | 한 소방ㆍ호안ㆍ방화ㆍ방책ㆍ보호시설 등의 설치 |
+------------------+---------------------------------------------------------+
| 3．취락지구 | 가．자연보존지구와 자연환경지구에서의 허용행위 |
| | 나．내무부령이 정하는 규모이하의 주거용 건축물의 설치 및|
| | 주민의 생활환경조성행위 |
| | 다．내무부령이 정하는 규모이하의 의원ㆍ약국ㆍ이용원ㆍ미 |
| | 용원ㆍ 일상용품판매시설등 취락지구의 자체기능상 필요|
| | 한 제반시설의 설치 및 행위 |
| | 라．공해를 발행하지 아니하는 가내공업 |
+------------------+---------------------------------------------------------+
| 4．집단시설 지구 | 가．심방휴양에 적합한 공원시설 및 그 부대시설의 설치행위|
| | 나．집단시설지구 지정이전의 기존 건축물로서 내무부령이 |
| | 정하는 규모의 개축ㆍ재축 및 수선행위 |
+------------------+---------------------------------------------------------+
③내무부장관ㆍ도지사 또는 군수는 제1 항의 용도지구를 공원계획으로 세분할 수 있다.
